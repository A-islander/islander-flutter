# Flutter 三岛接入规格

日期：2026-09-07；发布更新：2026-09-08。首轮实现纳入 v0.0.3；阶段进度见第 7 节，验证与保留项见第 10 节及 [发布说明](../releases/v0.0.3.md)。

后续写入阶段在 `feat/external-posting` 开发，见 [外站发帖规格](external-posting.md)。下文“不接入外站写入”描述首轮及 v0.0.4 已发布范围，不代表新分支的能力。

## 1. 目标与基线

在现有 Flutter 客户端内共同访问岛民岛、X 岛和 BOG。保留已确认的论坛布局、海绿色重点色、系统深浅色、帖子浏览、引用、颜文字、编辑抽屉及返回体验，不重新设计三套界面。

设计时 Flutter 正式版本为 `v0.0.2`，仅接入岛民岛。按帖懒加载、海浪绘制及返回动画性能优化随 v0.0.3 交付，不能将其视为已完成真机性能验收。

CLI/TUI `v0.0.2` 已有三站读取适配器，可复用其业务契约、解析规则及测试样例。TUI 的 `feat/persistent-forum-state` 工作区已有状态持久化实现，但尚未提交完成、合并或发布；不可据此声称 Flutter 已支持相关能力。以上为记录时的状态。

## 2. 范围决策

| 范围 | 本期要求 |
| --- | --- |
| 三岛浏览 | 站点切换、板块、时间线、分页、读串、引用、媒体展示 |
| 岛民岛写入 | 保留发串、回复、上传、我的内容、SAGE、删除与恢复及原有确认流程 |
| X / BOG 写入 | 本期不接入；不显示可用的发布或管理入口，调用层返回 `unsupported` 且不发请求 |
| 状态 | 记住上次岛、每岛导航和阅读位置、浏览历史、饼干与草稿隔离 |
| 草稿修订 | 后续可选增量，不作为首期三岛浏览的交付前提 |
| 平台 | 优先原生 Flutter 端；首先验证 Android，其他原生平台按实际构建与测试标记支持 |
| Web | 单独验证每站跨域及身份能力；不可用时提供明确说明和外部网页入口 |

本期不做混合三岛信息流、不实现海浪之家、不增加后端代理、不改签名或发布版本。外站发帖、上传、验证码、管理与服务端编辑历史均需独立规格及真实接口依据。

## 3. 界面与交互

- 在桌面侧栏和手机导航中提供站点选择，当前站点持续可见；标题、历史条目和编辑器目标区明确来源。
- 每岛独立保留板块、时间线和可用功能入口。能力检查同时作用于 UI 与业务调用层，不用空列表或假成功代替未支持功能。
- 保留中间页向前加载、触底向后加载、第一页下拉刷新、底部刷新入口与返回位置。跳页、总页数及末页按钮按实际分页能力显示，不强套岛民岛固定每页 20 条的算法。
- 引用就地展开，可继续查看嵌套引用；按完整来源编号检测循环并限制深度。裸编号只在当前岛解析，跨岛引用必须有明确来源。
- 保留换行、颜文字、正文引用和媒体信息；不得把外站不受控 HTML 作为可执行页面渲染。
- 宽屏预览停留约 180ms 后加载，最多展示五条回复摘要；快速切换取消旧预览，预览不记录正式阅读历史。窄屏直接进入串详情，不批量预取离屏串。

## 4. 架构与数据契约

采用“共用 UI → 站点会话 → 统一 ForumRepository → 三个 Dart 适配器”。不在 Flutter 中运行 CLI，也不通过 FFI 包装 Go。协议、错误码、Cookie、分页转换和引用语法留在适配器内。

建议分层：`features/forum/domain/` 放模型与接口，`data/adapters/` 放三站实现，`application/` 放会话、分页、历史与发布协调；现有页面通过兼容层逐步迁移。不要同时重写滚动 UI 和全部网络逻辑。

| 契约 | 必须满足的规则 |
| --- | --- |
| 站点实例 | `siteId` 为 `islander/x/bog`；`SiteInstanceKey` 包含站点类型和规范化 endpoint 配置摘要，正式服与测试服隔离；endpoint 禁止嵌入凭证 |
| 帖子身份 | `PostKey = siteInstanceKey + 原站 postId`，原站 ID 使用字符串；不同岛同号帖子不是同一条 |
| 板块 | 保留原站字符串 key；BOG 使用原始板块名，不能把 Go 兼容导航用的 CRC32 编号当作发布接口 ID |
| 帖子语义 | 区分主楼、回复、父串未知；父串可空，不能用 `followId=0` 伪装未知父串；X 作者 hash 不用于岛民岛所有权判断 |
| 分页 | 返回当前/下一页 token、真实 `hasMore`、可空总数及可空楼层偏移；主楼独立保留，不随翻页重复插入 |
| 引用 | 携带来源实例、目标编号、可空父串和原始链接；父串未知时展示引用内容，不猜测所属串 |
| 身份 | 业务状态只传本地身份引用、凭证类型及验证状态，不传或记录饼干明文 |
| 能力 | 显式声明浏览、验证、发布、上传、我的内容、SAGE、管理和定位等能力 |

切站或切身份时，保存旧状态，取消旧请求并增加会话/页面代次。provider、引用缓存及内容缓存按站点实例与身份隔离。异步结果必须匹配实例、身份代次和页面代次，不能仅检查 `mounted`。

## 5. 适配器与安全边界

以下为已有 CLI 适配契约，开发时先移植本地 fixture，再进行只读验证；不是对外站接口长期稳定性的保证。

| 站点 | 读取入口 | 身份与解析要求 |
| --- | --- | --- |
| 岛民岛 | `https://forum-api.islander.top/`；身份 `https://user-api.islander.top/` | 保留现有 `Authorization`、成功码 200 及发布逻辑，页索引转换由适配器处理 |
| X 岛 | `https://api.nmb.best/api/`；`getForumList`、`getTimelineList`、`timeline`、`showf`、`thread`、`ref`、`getCDNPath` | `userhash` 值原样保留百分号编码；兼容字符串数字、过滤 Tips；时间线 ID 动态读取；`ref` 不提供父串 |
| BOG | `https://bog.ac/`；`/f/时间线/页码`、`/f/板块名/页码`、`/t/串号/页码`；引用 `/api/thread/ID` | 列表/串页解析 HTML，引用 JSON 成功码 6001；使用 `bog_master`、`bog_sel`，可选 `bog_list`；必要 DOM 或页码不符应报解析错误而非空列表 |

每站独立 HTTP 客户端或等效不可变配置。岛民岛鉴权拦截器不能复用于外站；媒体请求不继承论坛凭证；携带凭证的请求不得自动跨目标重定向。解析错误和日志不回显饼干，HTML 清理 script/style 与危险内容。

X 现有验证方式为受限 AI 板块的只读访问；BOG 目前仅有 Cookie 格式检查，必须显示“未验证”，不得宣称已验证账号。没有明确授权，不使用真实饼干作测试；写操作使用本地模拟服务，不向正式站发布测试内容。

Flutter Web 的 Cookie 请求头及跨域读取受浏览器约束，`withCredentials` 不等于接口可用。不得为接通 Web 默认将外站饼干发送给岛民岛后端。代理若有需要，另行确认部署、目标白名单、凭证流向及限流。

## 6. 状态、历史与迁移

启动优先级：显式深链接/启动目标 → 有效的上次站点实例 → 默认岛民岛。切站成功激活配置后即记录选择，不以网络成功为前提；离线时显示重试，不偷偷切回其他岛。

导航、阅读、历史和草稿按站点实例及本地身份 ID（或匿名作用域）保存。切回该岛恢复板块、排序、列表锚点和阅读页；不恢复其他饼干的私有页面。状态文件不得重复保存 Cookie。

阅读锚点使用“稳定帖子 ID + 帖子内相对位置 + 页 token”，像素偏移仅辅助。目标楼移动时优先使用定位能力，否则最多查相邻前后各一页；找不到时明确回退，不扫描整个长串。帖子不可访问时保留历史并提示。

浏览历史只在串成功成为前台阅读页后记录；预览和引用预取不算访问。同串合并更新。首期建议默认每站点实例/身份最多 500 条、保留 90 天，不缓存全文及附件；这些是可调整的产品值，不是接口限制。提供按岛筛选、标题/编号搜索、单条删除、清空与关闭记录。删除/清空需确认，关闭后停止持久阅读足迹；旧异步保存不能恢复已删除的记录。

阅读状态约 500ms 合并保存，离页、切站、退后台补存。草稿延续现有 350ms 自动保存、生命周期保存及失败恢复，绑定创建时的岛、身份和发布目标。发送前重新核对绑定与站点限制；恢复不自动发送，结果不确定时不自动重发。

附件区分已上传引用和本地待上传文件；恢复时校验可用性，丢失时要求重选，不静默漏传。草稿并非加密云备份。可选修订功能每稿建议最多 20 个不同快照，恢复旧版形成新修订；发布成功后清除当前稿与快照，不伪装成服务端编辑历史。

现有 `islander.cookie-vault.v1` 与 `islander.draft.v1.*` 只迁入默认岛民岛实例。先读取验证旧数据，再写新版本并验证可读，最后标记成功；失败保留旧数据。存储分域版本化、串行写入并校验 revision，损坏数据局部隔离，禁止旧快照覆盖新状态。原生凭证继续使用安全存储。

## 7. 实施阶段与退出条件

以下标记表示本地实现与自动化验证，不等于 APK 已发布；完整产品验收仍须包含真机与平台验证。

- [x] M1：抽离领域接口并包装 IslanderAdapter；现有功能测试通过，旧饼干/草稿可读，保留未发布性能改动。
- [x] M2：实现 X/BOG 只读适配器、fixture 测试及原生只读联通验证；分页、引用和解析错误语义真实。
- [x] M3：接通站点选择与能力门控，完成凭证、缓存、请求及草稿隔离；三岛可独立浏览，岛民岛写入不退化。
- [ ] M4：实现上次站点、每岛阅读恢复和历史入口，完成旧存储迁移与故障恢复测试。M1–M4 为本期验收范围。
- [ ] M5（可选后续）：草稿修订快照、恢复与附件生命周期增强；独立验收，不阻塞首期浏览。

M4 的本地存储、历史界面、启动与切岛恢复、有限相邻页查找已实现；图片迟到、字体变化、不可访问长串等真机恢复边界尚未完成验收，因此暂不勾选整阶段。

外站发布与管理另立阶段；APK 构建、版本号、签名和 Release 发布不在本次文档任务中。

## 8. 验收清单

- [x] 三岛相同串号、同名饼干、不同 endpoint 的数据和权限互不混淆；切站后的旧响应不得覆盖当前页面。
- [ ] 总数未知仍能下一页；主楼不重复；双向连续加载、刷新、跳页与阅读锚点按能力正确工作。
- [ ] 引用保持来源、支持嵌套与循环保护；X 父串未知不伪造导航；BOG 结构失效明确报错；颜文字与媒体正确显示。
- [x] X/BOG 不支持的写操作不产生 HTTP 请求；BOG 格式校验不冒充身份验证；图片请求与错误日志无论坛凭证。
- [ ] 重启恢复上次岛，显式深链接优先；离线、帖子删除和记录损坏有明确回退，不覆盖有效旧数据。
- [x] 历史预览不计数、重访去重、关闭后停止记录；删除或清空后旧 timer 不复活数据。
- [ ] 草稿切岛、切身份、后台及重启恢复不串目标；旧写入不覆盖新文本，附件缺失有提示，失败不丢稿且不自动重发。
- [x] 岛民岛发串/回复、SAGE、我的内容、删除/恢复确认、旧饼干及草稿迁移回归通过。
- [ ] 保留按帖懒加载及海浪绘制优化；在 Android 真机 profile 下核对滚动、双向加载与返回帧耗时，记录机型和模式，不用 debug 观感代替性能验收。
- [ ] Web 按站记录实际可用能力与回退，未测试平台不在发行说明中标为已支持。

## 10. 首轮实现记录（2026-09-07）

落点：`data/adapters/{islander,x,bog}_adapter.dart`、`domain/forum_site.dart`、`application/{site_scope,external_identity,forum_state_store}.dart`，以及共用页面、外站饼干抽屉与历史抽屉。路由 `/s/x/...`、`/s/bog/...` 固定来源，旧岛民岛路由保持兼容；页面级 ProviderScope 隔离仓储与板块请求，外站切身份重建不可变 HTTP 会话并取消旧客户端请求。宽屏停留 180ms 后按需补充最多五条回复预览，离开后丢弃旧结果，不写阅读历史。

兼容策略：现有 Post / Plate 保留为页面桥接模型，增加字符串来源 ID、PostKey、板块 key 与父串未知语义；路由的帖子编号暂仍为三站当前使用的整数，不宣称已支持任意非数字帖子 ID。原始 `followId` 不能单独判断外站未知父串，应使用 `parentUnknown/isRoot/parentId`。

存储策略：默认正式岛民岛实例沿用 `islander.cookie-vault.v1` 和 `islander.draft.v1.*`，不是将旧数据复制给各岛；非默认 endpoint 使用含实例摘要的独立键。外站饼干为 `islander.external-vault.v1.<instance>`，原生使用安全存储；浏览状态 `islander.forum-state.v1` 不含凭证。历史与位置有限保留、串行写入，清空推进代次阻止旧会话写回。外站当前没有发布草稿，因此不会继承岛民岛编辑器或提交目标。

验证记录：

- 最终完整自动化测试：126 项通过，1 项真实联网测试默认跳过；外站适配、跨岛界面、状态/凭证隔离、宽屏预览与锚点恢复及既有论坛回归均覆盖。
- 另行启用匿名只读 smoke：X 返回 61 个板块，BOG 返回 17 个板块，双方时间线、串详情与引用均读取成功；未使用真实饼干、未发布测试内容。
- 静态检查无问题；Web 已完成编译检查，产物位于忽略的 `build/multi-forum-web`。这不代表已验收浏览器 CORS、外站登录或 Android 真机流畅性。
- 联网验证入口：`flutter test --dart-define=RUN_EXTERNAL_READ_SMOKE=true test/external_read_smoke_test.dart`。普通 `flutter test --concurrency=1` 不访问真实外站。

未完成/不在本轮交付：M4 真机恢复边界与 profile 性能验收、Web 每站跨域实测、iOS/桌面独立构建与运行验证、草稿修订和附件托管、外站发布与管理。X 导入验证实现尚未用用户真实饼干验收，BOG 仍为未验证。

2026-09-08 发布补充：同正式证书的本地测试包已在 Android 真机保留数据覆盖安装，屏幕中部右滑打开侧栏通过验证。v0.0.3 增加预览换行合并、延后省略；发行验证与下载见 [v0.0.3](../releases/v0.0.3.md)。上述 126 项为首轮实现时记录，不含后续新增手势和预览测试。
