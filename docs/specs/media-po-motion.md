# 图片保存、PO 与分层动效

日期：2026-09-08。纳入 v0.0.4（0.0.4+5）。

## 图片保存

- 大图右上角“保存原图”；长按大图执行同一动作，下载中禁止重复点击；可查看下载进度及中文成功／失败提示。
- 原图 URL 与缩略图分开，下载原始文件字节，不重编码 GIF。文件按 `islander-站点-帖子号-图片序号.扩展名` 命名，重名由保存平台处理。
- Android 使用相册保存；Web 通过 Blob 下载交给浏览器，不声称能确认文件已落盘；桌面使用原生保存对话框。视频暂不下载。
- 独立 Dio 实例不携带论坛饼干、Authorization 或其他站点身份。仅允许无内嵌凭证的 HTTP(S) 地址，不自动跟随重定向；错误不打印 URL、请求头或平台原始异常。
- 40 MB 大小上限，校验常见图片文件头；权限拒绝、磁盘不足、格式不支持、网络失败均提示。关闭查看器取消尚未完成的下载；已提交系统相册的保存不能撤回。
- Web 跨域受限时不尝试绕过浏览器安全机制，使用“打开原图”兜底；受保护图片不自动追加饼干。
- 相册接入遵循 [Gal 2.3.3 文档](https://pub.dev/packages/gal/versions/2.3.3)，Android 旧系统的存储权限仅声明至 API 29；不请求现代 Android 全相册读取权限。桌面保存遵循 [file_selector](https://pub.dev/packages/file_selector)。
- 仓库目前没有 iOS 工程，虽然保存层预留 iOS 分支，仍须创建工程、补齐 Info.plist 相册用途说明并真机验收，不能视为已交付 iOS。

## 串主 PO

- 主楼显示 PO；回复与最近回复预览仅在同站点实例、同父串、同可比较作者身份时显示。
- 岛民岛使用大于零的 userId，不比较昵称。外站使用独立 authorId；当前保守接受 7–12 位字母数字身份，未知或特殊标签不猜测；X 管理员公开标记不作唯一身份。
- 跨串引用获取被引用串的根串，根串未知或读取失败时不展示猜测的 PO；引用预览不写入浏览历史。

## 动画与页面结构

- 页面转场只传递动画状态，阅读区单独消费缩放／透明度；顶栏、宽屏侧栏、海浪不参与缩放。
- Android 左右系统预测返回：阅读区围绕自身中心等比缩小最多 8%；取消约 140ms 回弹，确认后约 200ms 缩到中心消失。普通返回也只作用于阅读区。
- 海浪使用根级共用时钟；切换页面不重置波形，不叠画两层海浪，弹窗不使海浪消失。
- 根级悬浮按钮层按路由切换，不使用 FAB Hero：旧按钮向下退出 140ms；新按钮延后 60ms，再从右侧入场并在 260ms 内完成轻微回弹。
- 回弹仅水平方向，振幅包络为 `6 × (1 - t)`，位移为 `-6 × (1 - t) × sin(4πt)`，约两次摆动，到终点精确归零。不是指数衰减，也不是匀速运动。
- 系统返回尚未确认时按钮保持原位；取消不重新入场。连续导航保留被打断按钮的当前横向位置后退场，不先跳回终点。
- 弹窗、编辑抽屉、侧栏遮住页面时隐藏按钮，不让按钮覆盖这些交互层；系统减少动态效果时跳过回弹和缩放。

## 验收范围

自动化覆盖图片原始字节与命名、无凭证请求、格式与地址错误、权限拒绝、取消下载、保存结果界面；PO 的身份／站点／父串隔离及跨串引用；阅读区居中缩放、固定顶栏海浪、共享海浪时钟、取消手势、按钮出入方向、线性振幅衰减、快速导航和减少动态效果。

真实相册权限与保存、Web 浏览器下载及原图跨域、真机高刷新率手感仍需验收。本次按用户要求发布独立 v0.0.4；原 v0.0.3 Release 保持不变，不自动安装到手机。

本轮验证：157 项完整自动化回归通过，1 项真实联网 smoke 默认跳过；静态检查无问题，Web 编译通过。新增原生保存插件已通过 ARM64／ARMv7／x86_64 debug 构建，产物遵循 islander 命名，留在忽略的 build/distributions 下；debug 签名不能覆盖手机上的正式签名版，未进行安装。
