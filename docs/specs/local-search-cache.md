# 浏览搜索与缓存配置

状态：纳入 v0.0.5，发布与验收范围见 [版本说明](../releases/v0.0.5.md)。下方验证记录保留各开发阶段的实际结果。只接入论坛功能，不涉及海浪之家。

## 页面和入口

- `/local-search`：保留内部路径兼容旧链接，页面、侧栏入口统一叫「浏览搜索」。移除顶部放大镜及独立「最近浏览」入口；现有页内筛选保持不变。
- 默认展示全部已缓存的主贴和回复，不按是否浏览过过滤。统一按 `COALESCE(browsed_at, accessed) DESC, rowid DESC` 排序：有浏览时间用浏览时间，其余用缓存访问时间，不再把浏览记录整体排在仅加载内容前。输入框提示仅「关键字/no号」，输入后搜索全部已加载内容，保留中文短词及标点的检索能力。每批 80 条。
- 筛选行左侧为全部／岛民岛／X／BOG，右侧为「多选」；移除顶部「永久保留」筛选按钮。多选进入零选中状态，勾选或点按逐条选择，清空选中仍保持选择模式；「完成」／取消退出。永久保留功能仍在帖子菜单、批量操作及缓存配置的保留项管理入口中，`?pinned=1` 保留兼容。
- 结果显示来源岛、帖子号和摘要。点击主贴进入对应岛原帖子页；点击回复进入所属串并携带 `focus`、`page` 定位信息。未知所属串只展示该条本地引用，不猜测父串。
- 长按进入多选，可保留、取消保留、导出、删除本地缓存；显式删除永久保留记录需确认。
- `/settings` 设置页提供 `/settings/cache`「缓存配置」入口；浏览搜索右上角也可进入。三页从左向右滑入，退出向中心缩小，复用论坛最大 8% 的预测返回缩放、取消恢复、确认收缩消失；减少动态效果时关闭转场。普通论坛页面的阅读区／顶栏分层不变。
- 现有帖子菜单增加永久保留、取消保留、单条导出、删除本地缓存，与服务器的删除／恢复操作明确区分。

## 数据与权限

SQLite 一条记录对应一个主贴或回复。内嵌的最近回复拆为独立记录，不保存整串 JSON 或重复嵌套回复。

在身份分区内，业务键是 **岛实例 + 帖子自身 ID**；物理唯一约束为 `(instance, identity, post_id)`。实例包含 API 地址指纹。当前实现保守地按所有身份隔离，而不是猜测某篇内容是否公开；搜索、离线读取只显示各岛当前身份分区。饼干切换不把旧身份记录并入新身份。

字段包含所属串、已知服务器页、首次正文 JSON、用于检索的纯文本、LRU 访问时间 `accessed`、主串浏览时间 `browsed_at`（可空，UTC epoch 微秒）、永久保留标记。凭据、饼干、草稿不进入数据库。

- 成功加载就缓存，包括列表最近回复和展开引用；不追踪是否真正进入视口，不自动拉取整个串。
- 只有前台帖子详情成功显示后才给主串更新 `browsed_at`；列表加载、回复及引用预览不写浏览时间。打开回复跳到所属串后记所属主串；未知父串的本地预览不猜测主串。关闭自动缓存时也暂停新增浏览时间。
- 旧数据库原地添加可空列和索引，不清库、不覆盖正文或永久标记。旧 JSON 历史按岛／身份一次性为已有缓存主串补回浏览时间，不覆盖更新的时间；只有标题、没有正文缓存的旧记录仍保留在旧状态数据中，不伪造原文。已迁移身份不重复导入，避免清缓存后旧历史复活。
- 首次正文保存后不覆盖；重复加载更新访问时间。未知所属串后来被服务端证实、或定位页变化时，只补充导航元数据。
- 搜索展示结果不更新 LRU；打开结果、读取离线正文、再次成功加载更新访问时间。
- 自动写入异步排队，网络结果无需等待落盘。缓存失败不会阻止在线阅读；当前数据库错误会在本地页面提示。
- 关闭自动缓存停止新增，不清除旧数据；已有缓存再次访问仍更新时间，用户主动永久保留仍可保存。
- 第一版仅保存正文和附件地址，不下载图片／视频。SQLite 未加密。永久保留不等于备份，卸载、系统清除数据仍会丢失。

## 搜索与容量

FTS5 trigram 索引处理三个及以上 Unicode 字符的子串检索，最后用字面子串校验；一、二字中文和短颜文字使用有界结果的 SQL 子串查询，不把 `%`、`_` 当通配符。查询参数化，输入防抖 250 ms。

默认 100 MB，可配置 1–2048 MB。预算按 SQLite 实际占用页计算，包含正文、检索文本、FTS 和普通索引；文件已分配空间单独显示，因为删除后的空闲页可复用，不会立即缩小文件。

超过预算时按 `accessed` 从旧到新清理，排除永久保留和当前离线阅读页持有的记录。永久保留占满预算时提示增大容量或取消保留，新普通记录可能无法留下，不自动删除保留项。手动「回收数据库空闲空间」执行索引整理和 VACUUM。

清理可按岛或全部，覆盖所选岛所有身份，默认保留永久内容。清理／修改配置递增写入代次，旧请求完成后不能立即重新写回被清理的内容；清理后新发起的加载仍可缓存。

新的最近浏览与正文合并在 SQLite：删除主串缓存也会删除该条浏览时间，仍须确认。新页面不再写旧 JSON 历史列表；阅读位置、饼干和草稿保持独立，不随缓存清理。

## 离线阅读

复用原有三岛帖子页，优先请求原站，失败后使用本机内容，显示「本地缓存 · 内容可能不完整」。只保留回复而主贴缺失时，明确显示主贴未缓存，不冒充完整讨论。

缓存中的服务器页只是定位提示，外站页面变化后可能找不到目标；提示未找到，不为定位扫描整个串。离线缓存页可能稀疏，跳过未缓存的页，不把缺页当作完整内容。仍可从浏览搜索打开其他缓存回复。

## 导入导出

`islander-cache-<UTC时间>.zip`，内含单个 `islander-cache.json`，格式标识 `islander-cache`，版本 1。正文、来源实例、父串、页提示、永久标记和原有附件地址；不含身份 ID、凭据、草稿或附件文件。

新增可选 `browsedAt` 字段保留主串浏览时间，旧备份缺失时视为仅加载未浏览；拒绝回复时间、负数、非整数与未来时间。同键原文仍不覆盖。

- 支持选中记录、设置页所选岛当前身份的全部缓存、仅永久保留导出。
- 单份压缩包和解压内容最多 32 MB、最多 100000 条；超过时分批导出。
- 导入前验证格式、版本、CRC、实例、ID 和导航字段；不解压任意文件路径到磁盘，拒绝链接和加密文件，限制解压输出。
- 导出按小批次读取稳定快照，累计到单份上限即停止，避免把用户配置的整个大容量缓存一次装入内存。
- 确认后映射到各岛当前身份，身份变化中止；同键记录不覆盖，新普通内容仍受 LRU 限额约束。
- Android 使用系统创建文档选择器保存 ZIP，无广泛存储权限；Web 浏览器下载，桌面用保存文件选择器。仓库目前没有 iOS 工程，未宣称 iOS 验收。

## 平台与构建

Android／Linux 使用 `sqflite_common_ffi` 后台执行和 SQLite 原生库；Web 使用 `sqflite_common_ffi_web` 与 IndexedDB 持久化。后者为实验性实现，浏览器清理站点数据会丢失内容；不同域、协议、端口存储隔离。当前包内固定 SQLite Dart 绑定 3.5.2，Web worker 与 WASM 一起提交。

Web 采用独立 Worker，规避本次 Chrome 回归中 SharedWorker 请求偶发停住的问题。使用 Web Locks 保持标签页级独占访问，防止多个独立 Worker 同时操作 IndexedDB 文件系统；另一个标签页的论坛在线功能照常，但本地缓存须关闭占用页后重试。需要支持 Web Locks 的安全上下文（HTTPS／localhost）；不支持时本地缓存不可用，不退化为无锁写入。

更新 SQLite 时必须同步生成 Web worker 和匹配 WASM，不直接使用 setup 默认的旧 3.1.2 二进制：

```sh
dart run sqflite_common_ffi_web:setup --force --no-sqlite3-wasm
curl --fail --location https://github.com/simolus3/sqlite3.dart/releases/download/sqlite3-3.5.2/sqlite3.wasm --output web/sqlite3.wasm
flutter build web --no-web-resources-cdn
```

官方实现说明：[sqflite_common_ffi](https://pub.dev/packages/sqflite_common_ffi)、[Web SQLite](https://pub.dev/packages/sqflite_common_ffi_web)、[FTS5 trigram](https://www.sqlite.org/fts5.html#the_trigram_tokenizer)。

Web 界面使用约 263 KB 的 Noto Sans CJK SC 字体子集，覆盖当前 Dart 界面文字，避免外网字体失败造成标签缺字；原生平台字体不变。子集来源、许可证与更新方式见 `assets/fonts/README.md`，不是完整汉字字体，其他字符仍沿用字体回退。
