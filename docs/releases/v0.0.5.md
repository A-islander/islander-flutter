# 岛民岛 Flutter v0.0.5

版本 `0.0.5+6`，2026-09-09。Android 正式签名分架构发布。

## 本版更新

- 新增「浏览搜索」，合并最近浏览，仅保留侧栏入口。默认展示三岛当前饼干身份下的全部已缓存主贴和回复，按浏览时间（未浏览时用缓存访问时间）倒序；搜索框为「关键字/no号」，右侧「多选」支持逐条勾选和批量操作。
- 新增设置与「缓存配置」：SQLite 逐帖保存、原文首次保存后不覆盖，默认 100 MB、可调至 1–2048 MB；支持 LRU 清理、永久保留、容量统计、清理确认和 ZIP 导入导出。点击结果进入对应岛的帖子并定位回复；网络失败时可阅读已有的不完整缓存。
- 原生 X／BOG 支持发串、回复、引用和图片；提交前确认站点与目标，身份切换拦截旧编辑器，失败保留草稿，BOG 已上传附件回执可复用。验证码及未知提交结果引导核对原站，不自动重试发帖。
- 冷启动进入上次所选岛的时间线第一页；设置、缓存配置和浏览搜索页从左向右进入，返回向中心缩小，保留预测返回与减少动态效果支持。
- 大图长按先弹操作菜单，不再直接下载；调试构建改为独立包名的「岛民岛调试版」，与正式版并存。

附带 `SHA256SUMS.txt`。沿用正式证书及包名 `com.islander.islander_flutter`，同架构的正式 v0.0.2–v0.0.4 可保留数据覆盖更新。更新前建议自行备份重要饼干与草稿；不要通过卸载或清空数据绕过签名问题。

独立调试版包名为 `com.islander.islander_flutter.debug`，与正式版数据不互通；本次正式 APK 不覆盖调试版。旧 v0.0.1／同包名 debug APK 的签名迁移说明见 [v0.0.2](https://github.com/A-islander/islander-flutter/releases/tag/v0.0.2)。

## 已知范围

- 缓存仅含正文与附件地址，不离线下载图片／视频，不包含图片下载去重。SQLite 与导出的 ZIP 未加密；永久保留不是备份，卸载或清除应用数据仍会丢失。单份 ZIP 上限 32 MB。
- 只搜索各岛当前身份的本机缓存，不请求原站搜索、不自动抓取整串。旧历史仅有标题而没有正文缓存时，不伪造原文；旧记录保留在原状态数据中。
- 外站协议可能变化；X／BOG 管理及 Web 外站写入仍不支持。本轮不使用真实饼干向正式服上传或发帖，真实站点最终接受结果仍需用户验收。
- 部分功能已通过独立 Debug 真机调试；最终正式 APK 的安装、系统文件保存器及断网完整交互未在手机验收。本次发布不自动安装或清除手机数据。
- Web SQLite 后端为实验性实现，需要匹配的 worker／WASM、HTTPS 或 localhost；使用独占标签页锁避免并发写入。海浪之家、iOS 工程及图片持久化缓存不在本版范围内。
- 正式版和调试版都连接正式服，发串、回复、删除等操作真实生效。
