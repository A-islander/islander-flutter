# 岛民岛 Flutter v0.0.4

版本 `0.0.4+5`，2026-09-08。Android 正式签名分架构发布。

## 本版更新

- 图片查看器支持保存原图、长按保存、进度与结果提示；Android 保存至相册，保留 GIF 原始文件。独立无饼干下载、40 MB 上限，权限或网络失败可打开原图。
- 主楼、串主回复与最近回复预览显示 PO；跨串引用按对应根串判断，不用昵称猜测身份。
- 返回只缩放阅读区，顶栏与海浪不动；手势最多缩小 8%，确认后收缩消失。海浪共享时钟，按钮向下退场、从右侧入场并线性衰减回弹；支持减少动态效果。
