# 岛民岛 Flutter v0.0.3

版本 `0.0.3+4`，2026-09-08。Android 正式签名分架构发布。

## 本版更新

- 预览标题、主串摘要和最近回复将显式换行合为空格，按原有 2／3／1 行上限显示，溢出才加省略号。详情正文、引用及颜文字空格保持原样。
- 手机可从屏幕内容中部右滑打开左栏，跟随手指展开；桌面 Web 窄屏补齐鼠标和触摸右滑，宽屏继续常驻导航。
- 三岛切换：岛民岛、X 岛、BOG 岛。外站支持只读列表、分页、串详情和引用，未知总数不显示末页；岛民岛原有发串、回复与管理保持不变。
- 外站独立多饼干管理；X 导入时验证访问，BOG 仅格式检查并明确标注未验证。原生端安全存储，Web 暂不导入或发送外站饼干。
- 按岛和身份隔离最近浏览、搜索、确认清理、上次站点及阅读位置；保留岛民岛现有饼干与草稿。
- 返回手势保留居中缩小最多 8%，提交收缩改为 200ms、取消回弹约 140ms；列表逐帖懒加载，海浪直接重绘以减少 Widget 重建。

|---|---|---:|
| `islander-android-v0.0.3-b4-arm64-v8a-release.apk` | 大多数现代手机 | 2004 |
| `islander-android-v0.0.3-b4-armeabi-v7a-release.apk` | 32 位 ARM | 1004 |
| `islander-android-v0.0.3-b4-x86_64-release.apk` | x86_64 设备／模拟器 | 4004 |

附带 `SHA256SUMS.txt`，下载全部附件后可用 `sha256sum -c SHA256SUMS.txt` 校验；单包下载请核对对应条目。

## 已知范围

- 默认连接正式服，岛民岛发串、回复、SAGE、删除／恢复会真实生效。
- X／BOG 暂不支持发布和管理，BOG 身份未经服务器验证；X 真实用户饼干导入尚待真机验收。
- 长串阅读恢复在图片迟到、字体变化、不可访问串等情况下仍待完整真机验收；性能改善不等于已完成 profile 帧率测量。
- Web 各外站跨域可用性尚未完整验收；本次仅提供 Android APK，不包含 iOS／桌面安装包。
- 海浪之家、草稿修订历史、外站附件托管不在本版范围。
