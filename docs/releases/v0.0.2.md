# 岛民岛 Flutter v0.0.2

## 重要：首次正式签名，旧版不能直接覆盖升级

本版使用项目外的正式 `islander-release` 证书，不再使用 Android Debug 证书。包名保持 `com.islander.islander_flutter`。

旧 GitHub `v0.0.1` 和本地 debug APK 与本版签名不同，本次未提供签名轮换链，Android 会拒绝直接覆盖安装。签名规则见 [Android 官方说明](https://developer.android.com/studio/publish/app-signing)。

迁移前请在旧版自行安全备份每一份饼干，并手动保存重要草稿正文、标题、引用和附件信息；确认凭证可用且备份完整后，再自行决定是否卸载旧版并安装本版、重新导入饼干。卸载或清空数据会丢失本机饼干和草稿；草稿不提供一键导出／导入或云端恢复。应用不自动卸载旧版、不自动迁移跨签名数据。不要将饼干发到 GitHub Issue、群聊或公开文档。

正式密钥以后保持不变。持有相同正式签名且版本码递增的后续同架构版本，可以按常规覆盖更新。

## 本版更新

- 多饼干管理：导入验证、去重、备注、切换、失效标记、复制及本机移除；Android 饼干使用安全存储。
- 发串／回复自动草稿：按饼干和板块／串隔离，保存标题、正文、引用与已上传附件信息；关闭恢复、发布失败保留、成功清理。
- 身份切换与请求隔离，防止跨饼干误发、旧请求的鉴权响应误退出新身份。
- 引用回复、SAGE、反对 SAGE、删除和恢复收进更多菜单；正文 `No.编号` 高亮点击展开引用，不再重复展示引用按钮。
- 删除／恢复串回复、移除饼干、清空草稿、复制饼干均需二次确认；“我的内容”增加未删除／已删除标签。
- 去掉第一页顶部提示和占位，前插上一页保持阅读位置；到底状态与刷新合为一个按钮。
- Android 页面预测返回：两侧均围绕整页固定中心等比缩放，拖动最多缩小 8%（至 92%），取消回弹，确认后继续缩到中心消失。支持减少动态效果；退出 App 回桌面仍由系统处理。

## 下载选择

要求 Android 7.0（API 24）或更高；版本 `0.0.2`，基础构建号 `3`。提供三个 release 模式、正式签名、非 debuggable 的 APK，不提供通用包。

| 文件 | 适用设备 | Android versionCode |
|---|---|---:|
| `islander-android-v0.0.2-b3-arm64-v8a-release.apk` | 大多数现代 Android 手机 | 2003 |
| `islander-android-v0.0.2-b3-armeabi-v7a-release.apk` | 32 位 ARM 设备 | 1003 |
| `islander-android-v0.0.2-b3-x86_64-release.apk` | x86_64 设备／模拟器 | 4003 |

同时提供 `SHA256SUMS.txt`。下载后可在同目录运行 `sha256sum -c SHA256SUMS.txt` 校验全部文件；只下载一份 APK 时可单独计算并核对其对应条目。以后保持选择同一架构，不要通过卸载来绕过版本码或签名不兼容提示。

正式签名证书 SHA-256（公开指纹，不是私钥）：

```text
BC:B7:83:EE:29:2D:FD:C7:7F:68:91:24:32:12:EA:A7:09:53:95:F2:83:13:93:BD:91:24:22:15:FC:CF:AA:DB
```

私钥及密码不随源码或 APK 发布。正式签名用于标识发布者和更新身份，不代表应用商店审核通过，也不能保证所有手机都不再显示侧载安全提示。

## 使用范围

- 默认连接岛民岛正式论坛与用户接口，发串、回复、投票、删除／恢复会作用于真实内容。
- 保留系统深浅色、像素海岸、双向连续加载、跳页、友链等功能；海浪之家尚未接入。
- “页内最新发布”只在各页内排序，筛选只搜索已加载内容，`No.编号` 支持跳转。
- 本次为 GitHub Android APK Release，不是 Google Play／其他应用商店上架，不包含 iOS 包。
- Android 自动备份关闭；请自行安全保管饼干。草稿是本机普通存储，不是加密云端备份。
